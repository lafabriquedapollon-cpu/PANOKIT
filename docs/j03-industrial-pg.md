# J03-C — PostgreSQL persistence lab
No LIVE, no API route or web change. Uses PG 17.12 embedded on loopback with SCRAM, ephemeral passwords and separate real SQL logins. Immutable revision/event history for non-owner roles, latest revision only, compare-and-swap writes, approval and terminal withdrawal, one statement snapshot reader, node policy digest recomputed and public projection never orderable. No public grants, owner NOLOGIN. Source integrity remains bounded: the trusted approver can record an assertion about a digest without actual document verification; SQL save accepts a bounded JSON draft, parser validates on read. SQL roles are service identities, not human Better Auth identities; no proof of real approval authorization, KMS or evidence storage. Snapshot read is point-in-time, no cache or checkout authorization. No multi-format list or production migration. All values are TEST_ONLY.
