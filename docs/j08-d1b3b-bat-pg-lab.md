# J08 D1B.3b — server-only PostgreSQL adapter
Dedicated connection per request with login/current role/database verification; exact own data properties, no caller-chosen session from JSON, raw token hashes only in SQL, server CSPRNG link and OTP generation, exact returned bytes digest verification, strict status projection. Fake SMS callback only after acknowledged COMMIT; no code in response, no blind retry on lost acknowledgement. Wrong/locked results commit to preserve attempts. Unknown commit response generic; subsequent authorized status can reconcile approval, never automatically replay. Thirteen unit scenarios T01–T13 and four actual PG17 A01–A04 include simulated loss of acknowledgement after real commit. No transport or public routes; caller is a trusted server session resolver and issuer service, no real phone proof or SMS. Base64 remains inert; browser rendering must vet/sandbox content. No claim of wall-clock validity through commit, delivery atomicity, independent timing review or complete recovery of an undelivered link.
